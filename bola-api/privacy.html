Kebijakan Privasi — Bola Api Arena

Berlaku sejak 27 Oktober 2026

Bola Api Arena adalah game sepak bola api yang berjalan di browser dan sebagai aplikasi Android. Kebijakan ini menjelaskan data apa yang diproses saat kamu bermain.

Tidak ada akun, tidak ada data pribadi yang dikumpulkan

Game tidak meminta nama, email, nomor telepon, atau login. Kami tidak mengumpulkan, menjual, atau membagikan data pribadi apa pun.

Penyimpanan di perangkat

Pengaturan game (suara, narator, tata letak tombol) disimpan hanya di penyimpanan lokal perangkatmu dan dapat dihapus kapan saja dengan menghapus data aplikasi atau data situs.

Mode online

Saat kamu memilih bermain online, game menukar data posisi permainan (koordinat pemain dan bola, skor, pilihan tim) secara real-time melalui layanan Supabase Realtime menggunakan kode ruangan acak. Data ini bersifat sementara, tidak berisi identitas, dan tidak disimpan setelah pertandingan selesai. Mode WiFi lokal menghubungkan dua perangkat secara langsung tanpa server.

Kamera

Kamera hanya dipakai jika kamu menekan tombol "pindai QR" untuk membaca kode ruangan dari layar teman. Gambar kamera diproses di perangkat dan tidak pernah dikirim ke mana pun.

Suara narator

Komentar narator dihasilkan oleh fitur text-to-speech bawaan perangkatmu. Tidak ada rekaman suara yang dibuat atau dikirim.

Anak-anak

Game ini tidak mengumpulkan data dari siapa pun, termasuk anak-anak, dan tidak berisi iklan pihak ketiga.

Perubahan

Jika kebijakan ini berubah, versi terbaru akan dipasang di halaman ini.
