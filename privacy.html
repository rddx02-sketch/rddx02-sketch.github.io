Kebijakan Privasi – Kutukan Si Oyen

Pengembang: Main Yuk · Berlaku sejak 26 Oktober 2026

Kebijakan ini menjelaskan bagaimana game Kutukan Si Oyen ("game") menangani data Anda.

Data yang kami kumpulkan

Game ini tidak mengumpulkan, tidak mengirim, dan tidak menjual data pribadi apa pun. Tidak ada akun, login, iklan, analitik, atau pelacakan pihak ketiga.

Data yang disimpan di perangkat Anda

Game menyimpan progres permainan (misi, uang dalam game, kucing yang dirawat) dan pengaturan (suara, ukuran teks, tata letak tombol) hanya di penyimpanan lokal perangkat Anda. Data ini tidak pernah dikirim ke server kami dan akan terhapus jika Anda menghapus data aplikasi atau mencopot pemasangan game.

Koneksi internet

Saat pertama kali dibuka, game dapat mengunduh file game dan huruf (font) dari Google Fonts. Seperti permintaan web pada umumnya, layanan tersebut dapat menerima alamat IP perangkat Anda sesuai kebijakan privasi Google. Setelah itu game dapat dimainkan tanpa internet.

Pembelian

Pembayaran game diproses sepenuhnya oleh Google Play. Kami tidak menerima atau menyimpan data kartu atau pembayaran Anda.

Anak-anak

Game ini tidak secara sengaja mengumpulkan data dari siapa pun, termasuk anak-anak.

Perubahan kebijakan

Jika kebijakan ini berubah, versi terbaru akan dimuat di halaman ini beserta tanggal berlakunya.

Kontak

Privacy Policy – Kutukan Si Oyen

This game does not collect, transmit, or sell any personal data. There are no accounts, ads, analytics, or third-party tracking. Game progress and settings are stored only on your device and are deleted when you clear the app's data or uninstall it. On first launch the game may load fonts from Google Fonts, which may receive your device's IP address under Google's privacy policy; afterwards the game works offline. Payments are handled entirely by Google Play. Contact: rddx02@gmail.com.
